# 黒電話ダイヤル

昔ながらの黒電話のダイヤルを指で回して電話をかけるミニゲームです。
正しい番号にかかると、つながった先の音声ガイダンスが流れます。

## 遊び方

1. 受話器をタップして上げる(「ツー」と発信音が鳴ります)
2. 数字の穴に指を入れて、右まわりに金具まで回して離す
3. 電話帳の番号を最後までダイヤルすると、相手につながる
4. 終わったら受話器を置く(「チン」と鳴ります)

- かける番号は、電話の下の電話帳にあります
- 伏せてある「ひみつの番号」は、ヒントの語呂合わせから当ててください
- つながった先には「済」のハンコが付きます(ブラウザに保存されます)
- パソコンでは、キーボードの数字キーでもダイヤルできます

## 音声について

ガイダンスはブラウザの音声合成で読み上げます。
音声合成が使えない環境では、字幕に合わせてピポピポ声が鳴ります。
Chromeなどのブラウザで開くのがおすすめです。

## 電話番号やガイダンスは、好きにアレンジしてね!

`index.html` ひとつだけで動いています。
中にある `BOOK` という一覧を書き換えると、電話帳を自由に変えられます。

```js
{ id: 'sento', num: '1126', name: '銭湯 松の湯', note: 'いい風呂',
  say: () => 'はい、松の湯です。本日も、いいお湯、わいてます。' },
```

| 項目 | 意味 |
| --- | --- |
| `id` | ほかと重ならない名前(半角英数字) |
| `num` | 電話番号(数字だけ) |
| `name` | 電話帳に出る相手の名前 |
| `note` | 名前の下に出るひとこと |
| `say` | つながったときに読み上げる文章 |
| `secret: true` | 付けると、つながるまで番号が伏せられる |
| `hint` | ひみつの番号のヒント |

行を増やせば電話帳も増えます。

### アレンジするときの注意

- ある番号が、別の番号の出だしと同じにならないようにしてください。
  たとえば `117` があると、`1177` には最後までダイヤルする前に `117` へつながってしまいます。
- ダイヤルの真ん中に書いてある自分の番号(`23-4567`)にかけると話し中になります。
  変えるときは `SELF` の数字と、ダイヤルに書いてある `23-4567` の両方を直してください。
- 電話帳にない番号にかけたときの案内は `WRONG` の文章です。
